## 🎵HarmonyHub

HarmonyHub es una aplicación para Android desarrollada con **Kotlin** que permite a los usuarios inscribirse en cursos de musica.

## 📱Características

- Interfaz de usuario moderna con Material Design
- Formulario de registro de usuario
- Selección de instrumento
- Pantalla de confirmación
- Navegación entre múltiples actividades

## 🛠️ Tecnologías

- Kotlin
- Android Studio
- Material Components
- XML ​​Layouts

## 📂 Estructura del proyecto

- MainActivity → Pantalla de bienvenida
- FormActivity → Formulario de registro
- ConfirmacionActivity → Confirmación de registro
